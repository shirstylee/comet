# Перед открытием репозитория

Техническая подготовка не меняет видимость репозитория на GitHub автоматически.

## Обязательное действие с ключом RAWG

Ключ RAWG ранее был записан в `lib/config/api_keys.dart`, начиная с коммита
`b82c103`. При проверке 206 доступных локально коммитов он встречался в 197
версиях этого файла. Текущий код читает `RAWG_API_KEY` из параметров сборки,
однако старое значение остаётся в истории.

Перед переводом репозитория в Public отзовите старый ключ в RAWG и получите
новый. Новый ключ сохраните только в игнорируемом `config/dart-defines.json`.
Не отправляйте его в чат, Issue, Pull Request или коммит.

При необходимости удалить и старое значение из истории следует отдельно
согласовать переписывание веток и тегов: оно меняет хеши коммитов и требует
принудительного обновления удалённых ссылок. Простого удаления файла или
добавления его в `.gitignore` недостаточно. Отзыв ключа необходим независимо
от очистки истории. Также проверьте ранее опубликованные сборки и вложения:
они могут содержать ключ, встроенный при компиляции.

## Финальная проверка владельцем

- [ ] Старый ключ отозван; новый ключ не отслеживается Git.
- [ ] Проверены права на изображения в `assets/` и другие сторонние материалы.
- [ ] Подходит режим **All rights reserved** из `LICENSE`: повторное использование
  требует разрешения, кроме прав, предусмотренных законом и условиями GitHub.
- [ ] Изменения закоммичены и отправлены; Flutter CI прошёл на GitHub.
- [ ] В настройках GitHub включены доступные проверки секретов, защита от
  отправки секретов и приватные отчёты об уязвимостях.
- [ ] После этих проверок владелец меняет видимость репозитория на Public.

## Проверки локально

```sh
flutter pub get
flutter analyze --no-fatal-infos
flutter test
flutter build apk --debug
git diff --check
```

Сборка без параметров RAWG проверяет компиляцию. Для проверки поиска на устройстве
используйте собственный ключ и инструкции из [README](../README.md).
